# Scarlet Frontier Log v0.7 — clean horizontal

Чистая версия без токен-попапов. Основная идея: одна широкая горизонтальная панель, импорт персонажа из большого HTML-листа, синхронный последний результат и компактный журнал.

## Как обновить

1. Распакуй архив.
2. Замени файлы в репозитории `Scarlet_Log`:
   - `manifest.json`
   - `index.html`
   - `style.css`
   - `main.js`
   - `icon.svg`
   - `README_RU.md`
3. Проверь, что `manifest.json` показывает версию `0.7.0`:
   `https://svenswanrig-netizen.github.io/Scarlet_Log/manifest.json`
4. В Owlbear используй ссылку:
   `https://svenswanrig-netizen.github.io/Scarlet_Log/manifest.json?v=070`

## Что умеет

- Импорт JSON персонажа из большого листа.
- Автоматически подтягивает имя, ОТП, ОД, SP, атрибуты, навыки и оружие.
- Горизонтальный боевой пульт без вкладок как главного интерфейса.
- Общий последний результат у всех игроков, у кого открыто расширение.
- Синхронный журнал через Owlbear Broadcast + Room Metadata.
- Журнал скрыт и открывается кнопкой `Журнал`.
- Урон: лёгкий, бронебойный, экспансивный с однократным взрывом.

## Важно

Онлайн-синхронизация работает только когда расширение открыто у участников в одной комнате Owlbear.
