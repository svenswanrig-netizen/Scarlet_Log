# Scarlet Log v0.8

Пробная чистая версия горизонтального боевого пульта для Owlbear Rodeo.

## Что изменилось

- Версия `0.8.0`.
- Исправлена сетка: элементы не должны накладываться друг на друга в поповере Owlbear.
- Добавлены всплывающие карточки результата внутри расширения. Если у игроков/мастера открыто Scarlet Log, бросок появляется у всех поверх панели.
- Лог остаётся архивом, а не главным местом просмотра броска.
- Импорт JSON стал заметнее: после загрузки показывается системное сообщение и всплывающее подтверждение.
- Пустой стартовый персонаж заменяется импортированным, чтобы не плодить одинаковых «Оперативников».
- Добавлена кнопка «Полный лист» — открывает локальный просмотр активного импортированного персонажа в новой вкладке.

## Как обновить

1. Распакуй архив.
2. Замени файлы в репозитории `Scarlet_Log`.
3. Проверь, что `manifest.json` показывает версию `0.8.0`.
4. В Owlbear используй ссылку:

```text
https://svenswanrig-netizen.github.io/Scarlet_Log/manifest.json?v=080
```

## Важно

Всплывающие карточки видят те участники, у кого открыто окно расширения Scarlet Log. Насильно открыть окно расширения у всех игроков Owlbear не даёт.
