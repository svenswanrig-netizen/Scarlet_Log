# Scarlet Frontier Log v0.12 — Bottom HUD

Полированная версия нижнего HUD для Owlbear Rodeo.

## Обновление

Замените файлы в репозитории `Scarlet_Log` и используйте ссылку:

https://svenswanrig-netizen.github.io/Scarlet_Log/manifest.json?v=120

## Что нового

- компактный режим больше не оставляет огромную тёмную пустоту;
- добавлен ручной выбор костей навыка прямо в HUD: `— / d4 / d6 / d8 / d10 / d12` для двух слотов;
- теперь можно быстро выставить `1d6`, `1d8`, `2d6`, `d6+d8` или Зеро без перезагрузки JSON;
- сохранены горячие клавиши, журнал, импорт JSON, ОТП/ОД/SP и урон.
