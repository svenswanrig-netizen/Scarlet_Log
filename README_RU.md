# Scarlet Frontier Log v0.6

Пробная версия с перепроектированным игровым потоком:

- результат последнего броска всегда показывается сверху в основном окне расширения;
- лог стал архивом, а не главным экраном;
- мини-панель токена показывает результат сразу внутри себя;
- события синхронизируются через Owlbear Broadcast и room metadata;
- данные токена сохраняются в metadata токена;
- контекстное меню токена: выбери токен на карте → Scarlet.

## Установка / обновление

1. Распакуй архив.
2. Замени файлы в репозитории `Scarlet_Log`.
3. Проверь, что `manifest.json` показывает версию `0.6.0`:

```text
https://svenswanrig-netizen.github.io/Scarlet_Log/manifest.json
```

4. В Owlbear используй ссылку:

```text
https://svenswanrig-netizen.github.io/Scarlet_Log/manifest.json?v=060
```

Если старая версия кэшируется, перезагрузи страницу Owlbear через Ctrl+F5.
