# Scarlet Frontier HUD v0.15.23

Версия с маркером цели и пипсами урона возле токена.

Что добавлено:
- контекстное меню токена:
  - **Scarlet** / B — связать токен с активным персонажем;
  - **Цель** / T — сделать токен целью;
  - **+Урон** — добавить 1 урон токену;
  - **−Урон** — снять 1 урон;
  - **Сброс** — очистить урон токена;
- возле токена появляется компактный маркер:
  - 🎯 если токен выбран целью;
  - ●●○○ как грубое состояние урона;
- маркеры создаются как отдельные scene items, чтобы их видели все игроки;
- точные события урона пишутся в общий лог;
- HUD не перегружен новыми кнопками.

Важно:
- токены не перезаписываются: маркер создаётся отдельным объектом;
- если Owlbear в конкретной комнате не даст создать text item, лог и состояние всё равно сохранятся, но визуальный маркер может не появиться;
- камера и автопереключение по клику по-прежнему выключены.
