# Scarlet Frontier HUD v0.16.0

Первая версия с двумя режимами HUD.

Что изменено:
- добавлены режимы **Сцена** и **Столкн.**;
- режим **Сцена** делает HUD компактнее и оставляет быстрый роллер + последний результат;
- режим **Столкн.** сохраняет полноценный боевой HUD с уроном, оружием, SP, логом и записью фактов;
- верхняя панель пересобрана: служебные кнопки теперь ближе к бренду, урон занимает центр;
- правый информационный блок в полном режиме стал шире;
- короткий лог не дублирует последний результат;
- журнал снова отдельный, не ломает основной HUD;
- сделана попытка менять высоту popover при переключении режимов, если Owlbear SDK это поддержит.
