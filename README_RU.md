# Scarlet Frontier Log v0.11 — Polished Bottom HUD

Полированная версия нижнего боевого HUD для Owlbear Rodeo.

## Обновление

Замените файлы в репозитории `Scarlet_Log` и используйте ссылку:

https://svenswanrig-netizen.github.io/Scarlet_Log/manifest.json?v=110

## Что нового

- компактный/расширенный режим HUD;
- кнопка «Новый ход»;
- горячие клавиши: `Ctrl+Enter` бросок, `Shift+Enter` урон, `J` журнал;
- более читаемый последний результат и компактный журнал;
- состояние журнала и компактного режима запоминается локально;
- импорт персонажа JSON, общий синхронный лог, ОТП/ОД/SP и урон.
