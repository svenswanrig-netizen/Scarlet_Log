# Scarlet Frontier HUD v0.15.22

Добавлены цель и камера.

Что добавлено:
- кнопка **Цель**: выбранный токен становится целью;
- строка статуса цели под персонажем;
- при выборе токена HUD показывает информацию о выбранном токене: имя, связь с персонажем, SP;
- если токен цели связан с персонажем HUD, берётся его SP;
- кнопка **Камера**: плавно подводит камеру к выбранному токену; если ничего не выбрано — к связанному токену текущего персонажа или к цели;
- урон может брать SP выбранной цели.

Безопасность:
- токены на карте не изменяются;
- бары, цвета, подписи и метаданные токенов не перезаписываются.
