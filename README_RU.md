# Scarlet Frontier HUD v0.15.21

Добавлена первая безопасная версия привязки персонажа к токену.

Как использовать:
1. Открой HUD в Owlbear.
2. Выбери токен на карте.
3. Выбери нужного персонажа в HUD.
4. Нажми **Токен**.
5. Теперь при выборе этого токена HUD будет автоматически переключаться на связанного персонажа.

Что важно:
- токены на карте не изменяются;
- бары, цвета, подписи и метаданные токена не перезаписываются;
- это только безопасная связь token ID ↔ персонаж HUD;
- если Owlbear не отдаст имя токена, HUD сохранит короткий ID.
