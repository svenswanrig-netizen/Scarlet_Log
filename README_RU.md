# Scarlet Frontier HUD v0.15.22 clean

Чистая версия от v0.15.21: действия с токенами перенесены из HUD в контекстное меню.

Что изменено:
- кнопка **Токен** убрана из верхней панели HUD;
- камера убрана;
- автопереключение HUD при клике токена отключено;
- добавлена строка **Цель** под строкой токена;
- через контекстное меню токена доступны действия:
  - **Scarlet** / shortcut B — связать токен с активным персонажем;
  - **Цель** / shortcut T — сделать токен целью;
- цель хранится в общем состоянии комнаты и отображается в HUD;
- токены на карте не изменяются.
