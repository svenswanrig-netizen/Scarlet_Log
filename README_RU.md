# Scarlet Frontier Log — Owlbear Rodeo extension

Это минимальное расширение для Owlbear Rodeo: общий лог бросков, ОТП, ОД и бросок урона.

## Что внутри

- `manifest.json` — файл, ссылку на который просит Owlbear в Add Extension.
- `index.html` — окно расширения.
- `style.css` — стили.
- `main.js` — логика бросков, ОТП/ОД, урона и отправка бросков через Owlbear Broadcast API.
- `icon.svg` — иконка расширения.

## Быстрый локальный тест

1. Открой терминал в этой папке.
2. Запусти простой сервер:

```bash
python -m http.server 5173
```

3. В Owlbear Rodeo открой профиль → Add Extension.
4. Вставь ссылку:

```text
http://localhost:5173/manifest.json
```

5. Создай/открой комнату и включи расширение.

Важно: `localhost` работает только на твоём компьютере. Для онлайн-игры нужно выложить папку на GitHub Pages/Vercel/Netlify и вставить уже публичную ссылку на `manifest.json`.

## Для GitHub Pages

Если репозиторий называется `scarlet-owlbear`, после публикации ссылка обычно будет такой:

```text
https://ТВОЙ_НИК.github.io/scarlet-owlbear/manifest.json
```

Именно эту ссылку надо вставлять в Add Extension.

## Ограничения этой первой версии

- Лог хранится локально в браузере и рассылается игрокам через Owlbear Broadcast.
- Если игрок открыл комнату позже, старые записи автоматически не подтянутся.
- Это MVP для проверки самой идеи: все видят броски и изменения ОТП/ОД.
