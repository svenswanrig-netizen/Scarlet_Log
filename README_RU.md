# Scarlet Frontier HUD v0.15.15

Новая более удобная версия для игроков.

Что изменено:
- журнал и лог объединены в одну выезжающую панель справа над HUD;
- панель журнала открывается как будто «из-за» HUD и не перекрывает его правую часть;
- правый блок в HUD теперь отдан под последний результат и заметную запись «Факт / реплика»;
- центр укорочен, кнопка «БРОСОК» выделена сильнее;
- K+/K- заменены на более понятные П+ / П−;
- доп. ОД теперь накапливается через избыток ОТП от магнумов (в том числе дубль-магнум), а не от обычного переполнения за любое получение ОТП.
