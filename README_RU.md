# Scarlet Log v0.5

Пробная сетевая версия для Owlbear Rodeo.

## Что есть

- Общая синхронная лента: чат, броски, урон, ресурсы.
- Новые события сверху.
- ОТП / ОД / SP.
- Сохранение последних событий в metadata комнаты.
- Контекстное меню токена: выбери токен на сцене и нажми **Scarlet**.
- Мини-панель токена рядом с токеном: ОТП / ОД / SP, быстрый бросок, сообщение в лог.
- Данные мини-панели сохраняются в metadata выбранного токена.

## Обновление

Замени файлы в репозитории GitHub Pages на файлы из этой папки.

Проверь manifest:

https://svenswanrig-netizen.github.io/Scarlet_Log/manifest.json

Должна быть версия 0.5.0.

В Owlbear устанавливай / обновляй по ссылке:

https://svenswanrig-netizen.github.io/Scarlet_Log/manifest.json?v=050

## Важно

Контекстное меню токена появляется после того, как основное окно Scarlet Log было открыто в комнате Owlbear хотя бы один раз.
Родной правый Dice Log Owlbear пока не используется: все события идут в Scarlet Log.
