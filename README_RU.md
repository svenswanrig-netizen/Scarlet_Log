# Scarlet Frontier HUD v0.15.16

Новая стабильная перекомпоновка HUD.

Что изменено:
- откат от неудачной идеи большого журнала внутри HUD;
- HUD стал немного выше, но без вертикального скролла;
- длинные поля «Проверка» и «Оружие» укорочены;
- правый блок стал сильно шире: последний результат + короткий лог + факт/реплика;
- «Факт / реплика» перенесены вправо к логу;
- кнопка «БРОСОК» визуально усилена;
- +К/-К заменены на П+/П−;
- исправлена логика доп. ОД от избытка ОТП при магнумах;
- журнал снова открывается отдельной панелью и не ломает основной HUD.
